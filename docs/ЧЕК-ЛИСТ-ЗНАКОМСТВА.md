# Чек-лист знакомства после установки

Отмечайте пункты по мере освоения программы. Ссылки открывают нужный раздел
полной документации (ярлык «Документация целиком» в меню Пуск или `docs\doc.html`
в папке установки). Ссылки вида `doc.html#…` работают с установленной программой; в репозитории
тот же текст — в файле `docs\ДОКУМЕНТАЦИЯ.md`.

## Куда класть несколько копий базы

Копия всегда пишется в `data\backups` программы. Дополнительные папки перечисляются
в «Настройках» через точку с запятой — программа кладёт туда и `psr_дата_время.db`,
и `psr.db`. Разумные варианты (не все сразу, обычно 2–3 направления):

* **Второй физический диск** того же компьютера: `D:\PSR-копии`
* **Съёмный SSD или флешка** — раз в неделю уносить в сейф: `E:\PSR-копии`
* **Сетевая папка / NAS** другой машины: `\\server\psr` (доступ по обычному общему ресурсу Windows)
* **OneDrive**: `C:\Users\Имя\OneDrive\PSR-копии`
* **Google Drive** (клиент с диском `G:\`): `G:\My Drive\PSR-копии`
* **Dropbox**: `C:\Users\Имя\Dropbox\PSR-копии`
* **Облако Mail.ru / RoboCloud / Selectel / Коммунарка (СБЕР)** — любой клиент, который
  показывает синхронизируемую папку в проводнике — указывайте путь к ней

Для **облачных** папок надёжнее копии с датой (`psr_20261022_0915.db`): живой `psr.db`,
который перезаписывается на каждом сохранении, синхронизатор может успеть перехватить
в момент записи. Для сетевой папки или второго диска это не страшно.

Облачные сервисы дают только хранение файла — сам файл SQLite программа открывает
локально, поэтому через облако работу **не делят** на двоих: для общей работы нужен
один компьютер (или перенос `data\psr.db` на время).
