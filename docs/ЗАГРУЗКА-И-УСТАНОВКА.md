# Загрузка и установка

Для кого этот файл: скачиваете программу и ставите её на компьютер сервисного центра.
Разработчики — [РАЗРАБОТЧИКАМ.md](РАЗРАБОТЧИКАМ.md), пользователи —
[ПОЛЬЗОВАТЕЛЯМ.md](ПОЛЬЗОВАТЕЛЯМ.md), полный справочник окон —
[ДОКУМЕНТАЦИЯ.md](ДОКУМЕНТАЦИЯ.md).

## 1. Что скачивать

| Файл | Где лежит | Что внутри |
|---|---|---|
| `PSR-ServiceCenter-Setup-1.0.1.exe` (≈17,3 МБ) | страница **Releases** этого репозитория, или папка `release\` в его корне | сама программа, библиотеки, запускатель, документация и чек-лист в HTML, значки |
| `PSR-ServiceCenter-Setup-1.0.1.exe.sha256` | там же, рядом с файлом | эталонная контрольная сумма установщика |
| Исходники, тесты, скрипт установщика | корень репозитория (`git clone`) | ≈2 МБ без артефактов сборки |

Одного `.exe` достаточно, других архивов не нужно.

**Проверить, что файл не повреждён и не подменён.** PowerShell в папке, куда скачали установщик:

```powershell
Get-FileHash .\PSR-ServiceCenter-Setup-1.0.1.exe -Algorithm SHA256
Get-Content   .\PSR-ServiceCenter-Setup-1.0.1.exe.sha256
```

Совпали — файл тот. Не совпали — перекачайте: у повреждённого архива программа установится,
но при запуске выдаст ошибку загрузки класса.

## 2. Требования к компьютеру

* Windows 7 64-бит, 10 или 11. На 32-битной Win7 не проверялось.
* Java 8 или новее — **если при установке не отмечен компонент «Свой Java»**. Проверить:
  `java -version` в командной строке. Нет Java — либо поставьте её (Java 8 x64 для Win7,
  свежая — для Win10/11), либо оставьте галку «Свой Java»: тогда своя Java 8 кладётся
  в папку установки и ничего системного ставить не нужно.
* Права администратора **не нужны**: программа ставится в папку текущего пользователя
  (`LocalAppData\Programs\PSR Service Center`) и пишет туда же, в `data\`.
* Свободных 200 МБ на диске (17 МБ сама программа + база и копии растут отдельно).
* Принтер — обычный (квитанции, акты, чек, этикетки листом А4). Принтер этикеток — по желанию,
  для пакета наклеек «По одной на страницу»; штрихкод Code 128 читается сканером-«клавиатурой».

## 3. Установка

1. Запустите `PSR-ServiceCenter-Setup-1.0.1.exe`. Windows 10/11 может показать
   «Система Windows защитила ваше ПК» (файл не подписан коммерческим сертификатом):
   «Подробнее» → «Выполнить в любом случае». Это ожидаемо для самодельного установщика,
   а не вирус — контрольная сумма в п. 1 тому подтверждение.
   Если антивирус корпоративный и файл всё же блокирует, добавьте папку установки в исключения
   и проверьте лог установщика (п. 7).
2. Страницы помощника:
   * **Компоненты** — «Программа» и «Документация и чек-лист в HTML» (оставить оба),
     «Свой Java» — если на этом ПК нет Java 8+.
   * **Папки для дополнительных копий базы** — установщик предлагает диски, сетевые папки
     и папки облачных клиентов, которые уже видны в проводнике. Берутся только **существующие**
     папки: новых установщик не создаёт. Лишние строки очистите, свои допишите — что останется
     в строках, попадёт в `data\backup-dirs.txt`, и программа примет список при первом запуске.
     Ничего не указали — настроите позже в «Настройки» → «Папки для дополнительных копий базы».
   * **Дополнительно** — ярлык на рабочем столе; папки `data\` и `modules\` создаёт сам.
3. Страница «Готово» предлагает три флажка: открыть чек-лист знакомства, открыть документацию,
   запустить программу. Чек-лист и документация открываются в браузере по умолчанию.
4. Первый запуск — окно входа: задайте **PIN администратора** (его знаете только вы), затем
   по чек-листу заполните «Настройки» (название центра, ИНН, адрес, логотип, целевой срок
   ремонта), добавьте инженеров в «Сотрудники, роли и доступ».

Где что лежит после установки:

```
LocalAppData\Programs\PSR Service Center\
  run.bat                    :: запуск (своя Java из jre\, иначе из PATH)
  psr-service-center.jar     :: программа
  lib\*.jar                  :: sqlite-jdbc, slf4j, javax-mail, zxing
  icon.ico / icon.png        :: значки ярлыков и окна
  docs\doc.html              :: документация, chek-list.html — чек-лист, versions.html — история версий
  data\psr.db                :: база (единственный носитель всех данных)
  data\backups\              :: копии базы
  data\attaches\             :: фото заявок и доверенности
  data\branding\             :: логотип
  data\export\               :: CSV/XML и выгрузка для Android
  modules\                   :: свои jar-плагины
```

## 4. Перенос на другой компьютер

Данные живут целиком в папке `data\`. Перенос:

1. Закрыть программу на старом ПК (при закрытии она сама пишет копию в `data\backups\`).
2. Скопировать `data\` целиком в папку установки нового ПК (поверх существующей — если там
   уже была база, старую не выбрасывать, а сложить в `data\backups\`).
3. На новом ПК поставить тот же установщик, при первом запуске программу можно не закрывать —
   база уже лежит на месте, PIN и настройки подхватятся.

Облако для **переноса** годится, для **общей работы** — нет: SQLite открывается одной машиной.
На двоих работают с одного компьютера (или переносят `data\psr.db` на время). Подробно —
глава 3 [ДОКУМЕНТАЦИЯ.md](ДОКУМЕНТАЦИЯ.md).

## 5. Удаление

«Программы и компоненты» → «Сервис центр от PSR» → «Удалить» (или `unins000.exe` в папке
установки). Снимаются программа и ярлыки, `data\` **остаётся** — так задумано.
Сносить `data\` можно только после проверки, что копии базы лежат минимум в двух других местах.

## 6. Если не запускается

| Симптом | Причина и что делать |
|---|---|
| Окно мелькнуло и пропало / «javaw не является внутренней…» | Java не найдена: поставьте Java 8+ или переустановите с компонентом «Свой Java» |
| Запускается на одном ПК, на другом нет | На «другом» Java 32-бит или Windows 7 32-бит; проверьте `java -version` и разрядность ОС |
| «Ошибка инициализации базы» / пустой список после переноса | `data\psr.db` скопирован в чужую папку или не дописан: верните файл целиком, сравните размер со старым ПК |
| Печать вместо принтера открывает OneNote/PDF | по умолчанию в системе стоит виртуальный принтер; в диалоге печати выберите реальный |
| этикетки печатаются, но сканер «не берёт» код | малое разрешение принтера: в «Наклейки (пакет)» поднимите толщину штрихкода (раздел 2.5.2 документации) |
| Копии не легли в облако | флешка вынута / клиент облака вышел из системы: «Настройки» → «Проверить папки копий» |

## 7. Сборка установщика своими руками

Нужны JDK 8+ (для сборки — `--release 8`), Node и Inno Setup 6
(`winget install --id JRSoftware.InnoSetup --silent`).

```
build.bat                              → build\psr-service-center.jar
installer\make-installer.bat           → build\dist\PSR-ServiceCenter-Setup-1.0.1.exe
installer\make-installer.bat "C:\jre8" → то же, но своя Java внутри (для Win7 — именно Java 8 x64)
set PSR_VERSION=1.1.0 && installer\make-installer.bat   → версия в имени файла
```

Проверка готового файла на этом же компьютере, тихо и в `%TEMP%`, без прав администратора:

```
build\test\install-test.bat        → ставится
powershell -File build\test\launch-test.ps1   → запускается, создаёт data\psr.db
build\test\uninstall-test.bat      → снимается, data\ остаётся
```

Лог любой установки установщик пишет в `%TEMP%` (`Log <дата>.txt`) — полное имя файла
появляется в конце работы. Разбор «на одном встало, на другом нет» начинают именно с него.
